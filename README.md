# 错题舱 · CuotiCang

> 一个单文件 HTML 的错题管理工具：拍照录题、框选标注、间隔复习、学情诊断、智能组卷，数据全留在本机。可选接入 DeepSeek 视觉模型，实现 AI 自动框选和知识点建议。

---

## 这是什么

"错题舱"是一个**零安装、零后端、离线可用**的错题管理工具。整个应用就是一个 HTML 文件，双击用浏览器打开就能用，手机浏览器也能打开。所有图片和题目数据都保存在浏览器的 IndexedDB 里，不上传任何服务器。

它想解决的问题很具体：**错题本抄了很多遍，错因还是那个错因**。所以它不只是"存错题"，而是把录题、归因、复习、诊断、组卷串成一条闭环，让错题真正被"消灭"。

---

## 功能一览

### 录题
- 拍照或从相册选图，支持一次多选
- 在图片上直接拖框，一道题一个框
- 每道题可标注：学科、册次、单元、知识点、错因、备注/答案/解析
- 错因分为五类：知识缺口、计算执行、审题偏差、思维路径、习惯问题

### 复习
- 基于间隔重复算法：`1 / 2 / 4 / 7 / 15 / 30 / 60` 天
- 四档评价：想起来了（升一级）、有点犹豫（保持）、完全忘了（归零）、又错了（归零）
- 掌握度是活的：连对拉长间隔，答错立刻归零，明天再见
- 掌握度 ≥ 5 级视为"已消灭"

### 诊断
- 总题数、平均掌握度、今日待复习、待攻克、已消灭
- 错因分布图
- 薄弱知识点排行（按平均掌握度从低到高，最多显示 10 个）

### 组卷
- 三种范围：待攻克 / 今日待复习 / 全部题目
- 三种版式：空白卷 / 自测卷 / 解析卷
- 勾选题目后一键生成，走浏览器打印，可另存为 PDF

### AI 辅助（可选，需 DeepSeek API Key）
- **AI 自动框选**：上传试卷图，DeepSeek 视觉模型返回每道题的归一化坐标，逐个进入填写表单
- **AI 建议知识点/错因**：框选一道题后，让模型根据题目图片建议学科、单元、知识点、错因和备注
- **测试连接**：设置页一键验证 Key 是否可用、模型是否可调用

### 数据管理
- 全部数据存于浏览器 IndexedDB
- 支持导出 JSON 备份（含图片）和导入恢复
- 支持一键清空

## 快速开始

### 方式一：直接用（离线核心功能）

1. 把上面的完整代码保存为 `cuoti.html`
2. 双击用浏览器打开（推荐 Chrome / Edge / Safari 新版）
3. 开始录题

不需要安装、不需要联网、不需要注册。

### 方式二：接入 DeepSeek（使用 AI 功能）

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并登录
2. 在左侧菜单进入 **API Keys**，点击 **创建 API Key**
3. **立刻复制** 以 `sk-` 开头的 Key（只显示一次，丢了只能重建）
4. 打开错题舱 → **设置** 页
5. 勾选「启用 AI」，粘贴 Key
6. 点 **测试连接**，提示 `连接成功：deepseek-flash` 即可

默认配置已经填好：

| 配置项 | 默认值 |
|---|---|
| API Base | `https://api.deepseek.com` |
| API 路径 | `/chat/completions` |
| 模型 | `deepseek-flash` |


## 数据安全

- **图片和题目只存在本机浏览器的 IndexedDB 里**，不经过任何服务器
- **API Key 存在本机 localStorage**，只会在你主动点击 AI 按钮时发给你自己填写的 API 服务
- 换设备、换浏览器、清理浏览器数据前，请先在「设置 → 导出 JSON 备份」保存一份
- 不建议在公共电脑上填写 API Key

> ⚠️ API Key 放在前端 localStorage 只适合个人本机使用。如果需要多人共用或多设备同步，必须改为后端代理，不要把 Key 暴露在前端。

## 技术说明

| 项目 | 说明 |
|---|---|
| 形态 | 单文件 HTML（HTML + CSS + JS 全部内联） |
| 存储 | IndexedDB（图片 blob + 题目元数据），localStorage（设置） |
| 图像 | Canvas 裁剪、ObjectURL 缓存 |
| 复习算法 | 简化版间隔重复，7 级阶梯 |
| AI | DeepSeek Chat Completions API（OpenAI 兼容格式），视觉输入用 base64 dataURL |
| 打印 | `window.print()` + `@media print` 控制卷面输出 |

## 已知限制

- **没有自动擦除手写笔迹**。纯前端离线做笔迹分割效果不稳定，建议直接用干净试卷拍照。
- **图片全量加载进内存**。启动时会把所有图片读成 ObjectURL，题量很大（几百张以上）时首屏会变慢。生产化可改成按需 `idbGet`。
- **AI 判分未接入 UI**。`aiJudge()` 函数已写好并接好 DeepSeek 视觉调用，但手写步骤和几何图的自动判分可靠性有限，建议保留"AI 初判 + 家长确认"的交互，不要完全无人值守。
- **单文件不适合多人协作**。没有账号体系、没有云同步、没有权限控制。
- **DeepSeek 视觉模型为实验性质**。官方标注为 Exp，可能快速迭代，模型名和接口以平台文档为准。

## 常见问题

**Q：一定要联网吗？**
A：不用。录题、框选、复习、诊断、组卷全部离线可用。只有点「AI 自动框选」「AI 建议知识点/错因」「测试连接」时才需要联网。

**Q：数据存在哪？换电脑会丢吗？**
A：存在当前浏览器的 IndexedDB 里。换设备或清理浏览器数据会丢。请在「设置 → 导出 JSON 备份」保存，新设备「导入 JSON」恢复。

**Q：DeepSeek 的 Key 收费吗？**
A：按量计费，视觉输入一张图最多折算 384 token，成本很低。新用户可能有免费额度，具体以平台当期政策为准。测试连接提示"余额不足"就需要先充值。

**Q：测试连接失败怎么办？**
A：依次检查：Key 是否以 `sk-` 开头且完整；API Base 是否为 `https://api.deepseek.com`（末尾不要多斜杠）；模型名是否为 `deepseek-flash`；账户是否有余额；网络是否能访问 `api.deepseek.com`。

**Q：支持手机吗？**
A：支持。手机浏览器打开 HTML 即可，`<input type="file" capture="environment">` 会直接调相机。

**Q：可以改错因分类或知识点吗？**
A：可以。错因在 `#fCause` 的 `<option>` 里改；知识点可以直接在输入框手填，`<datalist>` 只是快捷建议。
