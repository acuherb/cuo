# 错题舱

本地优先的错题本：拍照框选试卷上的错题 → 打标签 → 按间隔复习 → 诊断薄弱点 → 组卷打印。
**纯前端单文件 + 零运行时依赖**，题目和图片都存本机浏览器，不启用 AI 时完全离线可用。

## 快速开始

```bash
npm start          # 等价于 node server.mjs，默认 http://127.0.0.1:8080/
```

打开 <http://127.0.0.1:8080/> 即可。需要 Node.js 20+（只用到内置模块，`npm install` 都不需要）。
在线体验：<https://acuherb.github.io/cuo/>（由 main 分支自动部署；静态站点上 AI 请用「直连模式」）。

> 也可以用 `python3 -m http.server 8080` 托管目录，或直接双击 `index.html`；但这两种方式下
> **代理模式不可用**、部分浏览器还会限制 `file://` 的 IndexedDB，因此推荐 `npm start`。

## AI 辅助（可选，默认关闭）

启用后可用：自动框选题目、建议知识点/错因、复习时 AI 判分。视觉模型为 `deepseek-flash`。

### 方式一：本地代理（推荐）

密钥只存在于服务端进程，浏览器永远拿不到：

```bash
DEEPSEEK_API_KEY=你的密钥 npm start
# 或复制 .env.example 为 .env 后填写，再手动 export
```

设置页「连接方式」保持「本地代理」，模型名可按需修改。服务端会：
- 只转发白名单字段（`model` / `messages` / `temperature` / `max_tokens` / `response_format`）；
- 拒绝跨源调用，避免本机代理被外部网站当作免费转发器；
- 限制请求体 12MB、上游超时 90 秒，且不记录密钥。

`GET /api/health` 可查看服务端是否已配置密钥。静态部署（如 GitHub Pages）没有这个接口：
请在该站点的「设置」里把连接方式切到「浏览器直连」（Key 默认只存当前会话），或另行部署服务端代理。

### 方式二：浏览器直连（仅本机单人）

设置页切到「浏览器直连」，填写 API Base / 路径 / Key。**此模式会让密钥出现在浏览器里**，
只适合自己电脑上使用；任何公开部署都不要用。默认不记住 Key（仅保留在当前标签页会话），
只有显式勾选「在这台设备记住 Key」才会写入 localStorage。

> 隐私：启用 AI 后，自动框选会发送缩放后的整张试卷图，建议知识点和 AI 判分会发送题目裁剪图，
> 接收方是你配置的 API 服务。未启用 AI 时图片从不离开本机。

## 数据与备份

- 存储：IndexedDB `cuoti-mvp`（图片 Blob + 题目记录），设置存 localStorage / sessionStorage。
- 图片入库前等比压缩到长边 ≤ 2000px 并重编码为 JPEG；送视觉模型的整图再缩到 ≤ 1600px。
- 「设置 → 数据」可导出/导入 JSON 备份（含图片），导入会校验结构、补齐缺省字段、刷新图片缓存。
- 录题页「删除这张图片」会连同该图下的题目一起删除，避免存储空间只增不减。
- 换设备、换浏览器、清理站点数据之前，请先导出备份。

## 目录结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用主体（HTML + CSS + 原生 JS，单文件） |
| `server.mjs` | 零依赖静态服务 + `/api/deepseek` 服务端代理 |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | PWA：离线缓存与安装 |
| `.env.example` | 服务端环境变量模板（不含密钥） |
| `test/smoke.test.mjs` | 纯逻辑、静态约束与服务端冒烟测试 |
| `.gitignore` | 排除密钥文件、备份、IDE 数据 |

## 安全须知

- 仓库里**不应出现任何真实 API Key**。早期存在过的明文密钥文件 `cuo-key.md` 已删除，且从未被
  git 跟踪或提交（`git log --all -- cuo-key.md` 为空）；`.gitignore` 仍保留 `cuo-key.md`、
  `*key*.md`、`.env*` 等规则，防止以后误提交。**删除文件不等于吊销密钥**：若那个旧 Key 还没在
  服务商控制台作废，请立即吊销并重新签发；吊销属于账号操作，工具无法代劳。
- 前端代码、`index.html`、测试与文档都不含任何真实密钥；需要密钥时只通过服务端环境变量提供。
- `server.mjs` 默认只监听 `127.0.0.1`。需要局域网访问时显式设置 `HOST`，并知悉此时同一网络内
  其他人也能调用你机器上的 AI 代理。
- 通过 `http://` 访问时才会注册 Service Worker；改动 `index.html` 后请递增 `sw.js` 里的
  `CACHE` 版本号或在开发者工具中注销 SW，避免用到旧缓存。

## 已知限制

- 组卷依赖浏览器打印（可另存 PDF），不同浏览器的分页效果略有差异。
- AI 判分对 handwriting / 几何图可靠性有限，结果仅供参考，不会自动改写掌握度。
- IndexedDB 数据按「浏览器 + 域名」隔离；换端口或换浏览器都看不到原来的数据，请用备份迁移。
